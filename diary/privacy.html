다이어리 2027 개인정보 안내

시행일 2026년 11월 18일 · 앱으로 돌아가기

1. 이 앱은

다이어리 2027은 한 사람이 자신의 일정과 기록을 관리하려고 만든 개인용 웹 앱입니다. 별도의 서버를 두지 않으며, 앱 화면은 GitHub Pages에서 정적 파일로 제공됩니다.

2. 구글 계정에서 사용하는 정보

구글 로그인으로 다음 두 가지 권한만 요청합니다.

  • Google 캘린더 일정 보기·수정 calendar.events
    일정을 화면에 보여 주고, 사용자가 직접 누른 경우에만 제목의 말머리와 완료 표시를 고치거나 새 일정을 등록합니다.
  • 이 앱이 만든 Google 드라이브 파일 drive.file
    미팅·구상·데일리·목표 기록을 담는 구글 시트 「다이어리 2027 기록」 한 개를 만들어 읽고 씁니다. 드라이브의 다른 파일에는 접근하지 않습니다.

3. 저장 위치

  • 일정과 기록은 사용자 본인의 구글 계정(캘린더, 시트)에 저장됩니다.
  • 빠르게 열기 위해 같은 내용의 사본과 로그인 정보(접속 토큰, 계정 주소)를 사용 중인 기기의 브라우저 저장소에 둡니다.
  • 앱 제작자나 제3자의 서버로는 어떤 정보도 보내지 않습니다. 광고, 분석 도구, 추적 코드를 쓰지 않습니다.

4. 제3자 제공

없습니다. 정보는 사용자의 브라우저와 Google 서버 사이에서만 오갑니다. 다만 앱 파일을 내려받는 과정에서 GitHub(호스팅)와 Google Fonts(글꼴)가 접속 기록(IP 주소 등)을 남길 수 있습니다.

5. 삭제와 권한 해제

  • 앱의 설정 화면에서 로그아웃하면 기기에 둔 사본과 로그인 정보가 지워집니다.
  • 구글 계정의 서드 파티 앱 및 서비스 화면에서 이 앱의 액세스 권한을 언제든지 해제할 수 있습니다.
  • 캘린더 일정과 기록 시트는 사용자의 구글 계정에 그대로 남으며, 사용자가 직접 지울 수 있습니다.

6. Google API 정책

이 앱이 Google API로 받은 정보를 사용하는 방식은 Google API 서비스 사용자 데이터 정책(제한적 사용 요건 포함)을 따릅니다.
